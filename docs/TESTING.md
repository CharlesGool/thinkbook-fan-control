# 测试清单

逐项测试新版的全部功能。每项写了「怎么做」和「应该看到什么」；标 🔁 的项测完要改回原来的设置。

**准备**

- 新版在 `C:\Users\Userme\DailyUse\`（`ThinkBookFanControl.exe` + `tbfc.exe`），PawnIO 2.2.0 已安装。
- 打开一个命令行窗口，`cd C:\Users\Userme\DailyUse`，下面的 `tbfc` 命令都在这里运行（不需要管理员）。`tbfc status` 可以随时看程序的实时状态。
- 准备一个能让 CPU 满载的程序（Cinebench R23、y-cruncher、Prime95 等，下文统称「烤机」）。
- HWiNFO 开着「传感器」窗口，方便对照频率、功耗和风扇转速。
- 测试期间留意温度；任何时候点「恢复自动并退出」都会把风扇交还 EC。

## 1. 启动与基础

- [ ] **1.1 启动**：双击 `ThinkBookFanControl.exe` → 弹 UAC → 主窗口出现，托盘有风扇图标；顶部显示 CPU 温度 / 频率 / 占用 / 功耗 / PL1·PL2 / 风扇1 / 风扇2。
- [ ] **1.2 单实例**：程序在运行时再双击一次 → 提示「已经在运行」，不会开第二个。
- [ ] **1.3 托盘**：关闭窗口 → 留在托盘；左键托盘图标 → 窗口回来；右键菜单能切换模式、曲线方案。
- [ ] **1.4 托盘提示**：鼠标停在托盘图标上 → 显示温度、功耗、两个风扇转速。
- [ ] **1.5 开机自启**：「安全与常规」→「开机自动启动」保持勾选 → 注销再登录（或重启）→ 程序自动出现在托盘，没有 UAC。
- [ ] **1.6 守护进程**：先切到固定转速 4000 → 任务管理器「进程」页的「应用」里选中「ThinkBook 风扇控制」→「结束任务」（不要用「结束进程树」）→ 几秒内风扇回到 EC 自动，转速明显下降，`tbfc status` 连不上 → 重新启动程序。
- [ ] **1.7 诊断报告**：管理员命令行运行 `ThinkBookFanControl.exe --diag C:\temp\report.txt` → 报告里有机型、PawnIO 版本、风扇接口和范围、CPU 频率 / 功耗、PL1 / PL2 / Tau、各电源模式的频率上限、联想策略值。

## 2. 风扇模式

每项切换后看顶部「风扇N · 目标 …」和实际转速，或运行 `tbfc status`。

- [ ] **2.1 均衡（系统默认）**：目标显示「自动」，转速由 EC 决定。
- [ ] **2.2 安静**：目标跟随安静曲线（约 65 °C → 2000 RPM，75 °C → 2600 RPM）。
- [ ] **2.3 性能**：目标跟随性能曲线（约 55 °C → 3000 RPM，65 °C → 3800 RPM）。
- [ ] **2.4 全速**：目标为最高转速（5500 / 5700 RPM），实际转速接近。
- [ ] **2.5 固定转速**：设 3000 → 两个风扇都到 3000 左右；取消「所有风扇同步」后分别设 2500 / 3500 → 各自生效。
- [ ] **2.6 自定义曲线**：切到「自定义温度曲线」→ 拖动曲线上的点 → 目标随曲线变化；橙色虚线是当前曲线温度。
- [ ] **2.7 曲线方案**：新建 / 另存为 / 重命名 / 删除；托盘「曲线方案」子菜单能切换。
- [ ] **2.8 预设复制**：在安静或性能模式点「将当前预设复制为自定义曲线」→ 新方案出现并切到自定义曲线。
- [ ] **2.9 设置保存**：改几个设置 → 退出 → 重新打开 → 设置都在。

## 3. 平滑调速

- [ ] **3.1 逐步变化**：在固定转速下从 2000 改到 5000 → 目标显示「2300 → 5000 RPM」这样的过渡，约 10 秒内升到位（默认升速 300 RPM/秒）。
- [ ] **3.2 降速更慢**：从 5000 改回 2000 → 按 150 RPM/秒逐步下降。
- [ ] **3.3 速率可调**：把升速改成 1000 → 再试一次，明显更快。
- [ ] **3.4 关闭平滑**：取消「逐步改变转速」→ 改固定转速，目标立刻跳到新值。🔁
- [ ] **3.5 高温保护不受影响**：见 4.1，触发时直接全速，不慢慢升。

## 4. 安全功能

- [ ] **4.1 高温保护** 🔁：把「高温保护」调到 75 °C → 烤机让温度超过 75 °C → 两个风扇直接全速，状态栏显示「⚠ 高温保护已触发」→ 停止烤机，温度低于 70 °C 后恢复原模式 → 改回原值。
- [ ] **4.2 低速 / 停转** 🔁：勾选「允许低于额定最低转速 / 停转」（有确认框）→ 固定转速设 0 → 温度低于设定值（默认 50 °C）时风扇停转，目标显示「停转」；温度超过设定值后自动回到额定最低转速 → 测完取消勾选。
- [ ] **4.3 睡眠唤醒**：在固定转速模式下睡眠 → 唤醒 → 几秒内目标重新生效。
- [ ] **4.4 恢复自动并退出**：点按钮 → 程序退出，风扇回 EC 自动；如果开着自定义 PL 或频率上限，也恢复成原值（`--diag` 或 HWiNFO 可确认）。

## 5. CPU 监控

- [ ] **5.1 频率 / 占用**：空闲时频率在 1–3 GHz、占用为个位数；烤机时占用接近 100%。和任务管理器「性能」页的速度、利用率大致一致。
- [ ] **5.2 实时功耗**：空闲约 10–20 W，烤机时升到 PL2 再回落到 PL1。和 HWiNFO 的「CPU Package Power」对比，应基本一致。
- [ ] **5.3 PL1 / PL2 数据块**：显示当前 MSR 里的 PL1 / PL2（平时常见 25 / 35 W，打开程序时可能临时变成 80 / 140 W）。
- [ ] **5.4 历史图**：下方历史图有风扇转速、CPU 温度和 CPU 功耗三类曲线，右侧刻度显示「°C / W」。

## 6. PL1 / PL2 / Tau

- [ ] **6.1 开启** 🔁：勾选「自定义 PL1 / PL2」→ 出现确认框 → 确定；把 PL1 设 35、PL2 设 50、Tau 下拉框选 28 秒 → 信息栏显示「✓ 已应用自定义值」，顶部 PL 显示 35 / 50 W。
- [ ] **6.2 实际生效**：烤机 → 封装功耗先到约 50 W，十几秒后回落到约 35 W 并保持（Tau 越大，保持 50 W 的时间越长；实测 Tau 8 秒时约 3 秒）。
- [ ] **6.3 Tau 下拉框**：下拉框只有 1–8、10、12、14、16、20、24、28、32、40…448 秒这些值；选 96 秒 → 信息栏显示 Tau 96 秒。`tbfc pl 35 50 100` → 自动取最接近的 96 秒。
- [ ] **6.4 PL2 不低于 PL1**：把 PL1 调到比 PL2 大 → PL2 自动跟着变大。
- [ ] **6.5 MMIO 显示**：信息栏里有「MMIO（动态）：PL1 … W · PL2 … W」；如果 PL1 设得比 MMIO 的值高，实际功耗以较低的那个为准，信息栏多出「实际生效：PL1 … W · PL2 … W」（每项取较低者）。
- [ ] **6.5a EC 改写动态 PL**：风扇设得低一些，烤机到温度墙 → 信息栏出现「动态 PL 最近一次变化：hh:mm:ss 由 … 改为 24 / 70 W，当时 CPU …°C」；自定义 PL 为 25 / 35 W 时「实际生效」是 24 / 35 W，满载功耗不超过 35 W。停止烤机降温后，看这一行是否又出现一次恢复的记录（记下 EC 是否恢复、多久恢复）。
- [ ] **6.6 被改回时保持**：开着自定义 PL，打开几个程序 → 若 PL 被系统临时抬高，信息栏会提示「打开程序后系统临时提高了 PL（N 秒后恢复设定值）」，之后回到设定值（取决于 8.4 的开关）。
- [ ] **6.7 关闭恢复**：取消「自定义 PL1 / PL2」→ PL 回到接管前的值（例如 25 / 35 W，Tau 8 秒）。
- [ ] **6.8 退出恢复**：开着自定义 PL 时点「恢复自动并退出」→ 再打开程序看 PL，应是接管前的值。

## 7. CPU 最高频率（P 核和 E 核一起限制）

- [ ] **7.1 开启**：勾选「按电源模式和是否插电限制频率」→ 若联想服务还在调节频率，会询问是否停止它（见 7.8）。
- [ ] **7.2 下拉框**：6 行（3 种电源模式 × 插电 / 电池）× 平时 / 全核满载；平时可选「不限制」或 5.4 GHz 往下每 200 MHz 一档，全核满载第一项是「同平时」。
- [ ] **7.3 插电生效** 🔁：插电、Windows 电源模式选「平衡」，把「平衡 · 插电」设 2.4 GHz → 信息栏显示「当前：插电 · 平衡 → 最高 2.4 GHz」→ 烤机，HWiNFO 里所有核心频率不超过约 2.4 GHz（E 核约 2.3 GHz）。
- [ ] **7.4 拔电源** 🔁：拔掉电源 → 信息栏变成「电池 · 平衡」，用的是「平衡 · 电池」那一格的值。插回电源后恢复插电的值。
- [ ] **7.5 切换电源模式** 🔁：Windows 设置 → 系统 → 电源 → 电源模式，切到「最佳能效」或「最佳性能」→ 信息栏的模式跟着变，上限用对应那一行的值。
- [ ] **7.6 不能单独限 E 核（已知限制）**：这是 Windows / 硬件的行为：只有一个上限，同时作用于 P 核和 E 核。
- [ ] **7.6a 平时 / 全核满载** 🔁：「平衡 · 插电」平时 3.4 GHz、全核满载 3.0 GHz → 空闲或只跑一个单线程程序时，信息栏显示「平时（负载约 1 核）→ 最高 3.4 GHz」→ 烤机（全部线程）后 0.5 秒内变成「全核满载（负载约 14 核）→ 最高 3.0 GHz」，约 1.5 秒内 HWiNFO 里频率不超过 3.0 GHz → 停止烤机约 1 秒后回到 3.4 GHz。
- [ ] **7.6a2 单核跑分** 🔁：「平衡 · 插电」平时选「不限制」、全核满载 3.0 GHz → CPU-Z 单线程测试时信息栏一直是「平时」，频率能到约 5 GHz，分数和不限频时相近。
- [ ] **7.6a3 多线程后紧接单线程** 🔁：同上设置，CPU-Z 点「Bench CPU」连续跑两次（第二次的单线程紧跟第一次的多线程）→ 第二次单线程的分数一开始就正常；信息栏约 1 秒内回到「平时」。
- [ ] **7.6a4 部分负载不限制**：同上设置，开 4–8 个满载线程（例如 CPU-Z「运行」选 4 线程的稳定性测试）→ 信息栏仍是「平时」，不限频。
- [ ] **7.6b 全核满载不高于平时**：把全核满载设得比平时高（例如平时 3.0、全核满载 3.4）→ 全核满载时仍是 3.0 GHz。
- [ ] **7.6c 最佳能效的单核频率（已知现象）**：最佳能效下即使选「不限制」，单核也跑不到最高频率：这是该模式的 EPP 和调度设置造成的，频率上限只能往下限，不能往上提。
- [ ] **7.7 电池睿频** 🔁：拔电源，不勾「电池供电时也允许睿频」→ 信息栏提示「睿频已关闭」，频率不超过基础频率；勾选后电池下也能睿频。
- [ ] **7.8 联想服务开关** 🔁：勾选「不让联想进程管理服务调节频率」→ 确认 → 几秒后勾选框恢复可用（服务已重启）；取消勾选 → 恢复原值并再次重启服务。
- [ ] **7.8a 停用联想进程管理服务** 🔁：勾选「停用联想进程管理服务（彻底不再改写频率上限）」→ 警告框点「确定」→ 几秒后勾选框恢复可用；`services.msc` 里 Lenovo Process Management service 已停止、启动类型「禁用」→ 开着频率限制烤机 / 打开程序一段时间，信息栏不再出现「被其他程序改写」，HWiNFO 里频率不再有尖峰。
- [ ] **7.8b Fn+Q**：服务停用时按 Fn+Q 切换模式 → 看信息栏的电源模式是否还跟着变（未实测；不变的话在 Windows 设置里切电源模式）。
- [ ] **7.8b2 启动时检查**：勾选 7.8a 后在 `services.msc` 里把服务改回「自动」并启动 → 重启本程序 → 几秒内服务又被停用、启动类型变回「禁用」，勾选框保持勾选。
- [ ] **7.8c 恢复服务** 🔁：取消勾选 → 服务恢复「自动」并在运行；`--diag` 报告里能看到三个服务的状态和启动类型。
- [ ] **7.9 关闭恢复**：取消「按电源模式和是否插电限制频率」→ 各模式的频率上限恢复成开启前的值（`--diag` 报告里可看到）。

## 7B. 性能偏好（EPP）

- [ ] **7B.1 初始值**：「性能偏好 EPP」分组的下拉框显示系统当前值（平衡 25 / 50，最佳能效 50 / 72，最佳性能 25 / 33）。
- [ ] **7B.2 开启不改变**：勾选「按电源模式和是否插电设置性能偏好」但不改下拉框 → 信息栏「当前：… → EPP 25」等，与开启前相同。
- [ ] **7B.3 最佳能效也能升频** 🔁：Windows 电源模式切到「最佳能效」，记下单线程负载（例如 Cinebench 单核）时的频率 → 把「最佳能效 · 插电」改成 25 或 0 → 再测，单核频率明显更高。
- [ ] **7B.4 更省电** 🔁：把「平衡 · 插电」改成 100 → 单核负载时频率明显降低（实测 2.9 → 2.3 GHz）。
- [ ] **7B.5 被改回时写回**：开着时正常使用一段时间 → 如有改写，信息栏显示「1 分钟内被其他程序改写 N 次，已立即改回」，EPP 保持设定值。
- [ ] **7B.6 关闭恢复**：取消勾选 → EPP 恢复成开启前的值（信息栏的当前值变回原值）。
- [ ] **7B.7 退出恢复**：开着时点「恢复自动并退出」→ 再打开程序，信息栏显示原值。
- [ ] **7B.8 和频率上限独立**：开着 EPP，关掉频率上限（或反过来）→ 另一个功能的值不受影响。

## 8. 系统改写与临时加速

- [ ] **8.1 改写提示**：频率限制开着时，正常使用一段时间 → 信息栏显示「1 分钟内被其他程序改写 N 次，已立即改回」。这是联想进程管理服务在改（7.8a 停用后应不再出现）。
- [ ] **8.2 不允许临时加速** 🔁：取消「打开程序时允许系统临时加速」→ 平衡 · 插电设 2.4 GHz → 从开始菜单打开几个程序 → HWiNFO 里频率一直不超过约 2.4 GHz；信息栏不出现「临时加速中」。
- [ ] **8.3 允许临时加速（默认）**：勾选后从开始菜单 / 任务栏打开一个**新程序**（例如计算器、画图、浏览器新开）→ 信息栏出现「打开程序后的临时加速中（N 秒后恢复设定值）」，倒计时约 10 秒 → 结束后频率回到 2.4 GHz 以内。
- [ ] **8.4 连续打开延长**：几秒内连续打开几个程序 → 加速时间延长，但最长约 30 秒。
- [ ] **8.5 切到旧窗口不算**：切换到早就开着的程序（不是新启动的）→ 不触发临时加速。
- [ ] **8.6 PL 也适用**：开着自定义 PL 时重复 8.2 / 8.3，PL 的表现和频率上限一样。

- [ ] **8.6a 停用 DTT 扩展组件** 🔁：勾选「停用 Intel DTT 扩展组件」→ 警告框点「确定」→ 几秒后设备管理器 → 软件组件里「Intel(R) Dynamic Tuning Technology Device Extension Component」带禁用标记 → 开着频率限制烤机 10 秒再停 → 信息栏不再出现「被其他程序改写」；取消勾选 → 组件重新启用。
- [ ] **8.7 剩余改写**：停用联想服务后正常使用 → 信息栏偶尔显示「被其他程序改写 N 次（Intel IPF / DTT 的处理器驱动在负载变化时把频率上限和 EPP 一起改了…）」，显示的当前上限始终是你的设定值，不会出现 5.0 GHz。

## 8A. 托盘切换电源模式

- [ ] **8A.1 切换** 🔁：托盘右键 →「电源模式」→ 选「最佳性能」→ Windows 设置 → 系统 → 电源里的电源模式同步变成「最佳性能」，信息栏「当前：插电 · 最佳性能」；再切回原来的模式。
- [ ] **8A.2 勾选标记**：再次打开「电源模式」子菜单，当前模式前有勾。
- [ ] **8A.3 命令行**：`tbfc power` 显示当前模式；`tbfc power balanced` 切到平衡。
- [ ] **8A.4 动态 PL**：停用联想进程管理服务和 DTT 扩展组件后重启 → HWiNFO 里 PL1 / PL2（动态）是 BIOS 设的值，用托盘切换模式时也不变。

## 8B. 界面

- [ ] **8B.1 刷新间隔**：「安全与常规」→「界面数值刷新间隔」选 3 秒 → 顶部数值和信息栏约 3 秒变一次；选 0.5 秒明显更快；重启程序后保持。下方历史曲线始终每秒一个点（5 分钟宽度不变）。

## 9. HWiNFO

- [ ] **9.1 传感器出现**：「在 HWiNFO 中显示」勾选 → 重启 HWiNFO → 传感器窗口最下面有「ThinkBook 风扇 Control」组：风扇 1 / 2、Fan N Target、CPU 温度、封装功耗、PL1、PL2、频率、占用。
- [ ] **9.2 数值更新**：这些值每秒刷新，和程序界面一致；目标为 0 表示「自动」。
- [ ] **9.3 重启提示**：取消「在 HWiNFO 中显示」→ 重启 HWiNFO（这时没有这组传感器）→ 重新勾选 → 约一分钟内托盘弹出「HWiNFO 需要重启一次」，状态栏也有提示 → 再重启 HWiNFO 后提示消失、传感器出现。
- [ ] **9.4 取消删除**：取消勾选 → 重启 HWiNFO → 这组传感器消失。🔁

## 10. 命令行 tbfc（本机）

- [ ] **10.1 status**：`tbfc status` 显示模式、CPU、两个风扇、PL、频率上限、性能偏好；`tbfc status --json` 输出 JSON。
- [ ] **10.2 mode** 🔁：`tbfc mode quiet` → 界面里的单选框同步切到安静模式；再 `tbfc mode performance` 等切回原来的模式。
- [ ] **10.3 fixed**：`tbfc fixed 3000` → 切到固定转速，两个风扇都是 3000（会打开「所有风扇同步」）；在界面取消「所有风扇同步」后 `tbfc fixed 3500 2` → 只改风扇 2。

- [ ] **10.5 pl** 🔁：`tbfc pl` 显示当前值；`tbfc pl 35 50 28` → 界面同步勾选并显示 35 / 50 / 28；`tbfc pl off` → 恢复。
- [ ] **10.6 freq** 🔁：`tbfc freq` 显示表格（平时 / 全核满载）；`tbfc freq balanced ac 3400 3000` → 界面两个下拉框同步变成 3.4 / 3.0 GHz；`tbfc freq balanced ac 3400` 只改平时；`tbfc freq off` / `on`。
- [ ] **10.6a epp** 🔁：`tbfc epp` 显示表格；`tbfc epp balanced ac 0` → 界面下拉框同步；`tbfc epp on` / `off`。
- [ ] **10.7 开关**：`tbfc boost off|on`、`tbfc dcturbo on|off`、`tbfc hwinfo on|off` → 界面复选框同步变化。🔁
- [ ] **10.8 错误处理**：`tbfc foo` → 「未知命令」，退出码 1；`tbfc --token 错的 status` → 「令牌错误」，退出码 1。
- [ ] **10.9 程序没运行**：退出程序后 `tbfc status` → 「无法连接」，退出码 2。
- [ ] **10.10 关闭命令行控制**：取消「命令行控制（tbfc.exe）」→ `tbfc status` 连不上；重新勾选恢复。
- [ ] **10.11 quit**：`tbfc quit` → 程序交还 EC 并退出（之后手动再打开）。

## 已知现象（不算问题）

- `tbfc status` 里「当前」那一行是上一秒的读数，刚执行完命令时会慢一拍。
- 打开程序时和负载变化后，频率上限会被联想进程管理服务临时改高，是系统行为；是否放行由 8.2 / 8.3 的开关决定，彻底避免用 7.8a。
- 全核负载开始的一瞬间（约 0.3–1.5 秒）仍是平时上限的频率：本程序要先看到负载才切换上限（7.6a）。
- 只有一个频率上限，同时作用于 P 核和 E 核（见 7.6）。
